Cara Mendapatkan Kunci API

Ikuti 4 langkah mudah untuk mendapatkan Google Gemini API gratis

  • 1
    Kunjungi Google AI Studio

    Buka situs resmi Google AI Studio pada browser Anda.

  • 2
    Masuk dengan Akun Google

    Gunakan akun Google yang aktif (gratis tanpa biaya langganan).

  • 3
    Klik "Get API Key"

    Pilih tombol Create API key in new project lalu salin kunci yang muncul.

  • 4
    Tempelkan & Simpan

    Tempelkan kunci berawalan AQ... (format baru) atau AIza... ke form di sebelah kanan lalu klik Simpan Kunci API.

Cara Mendapatkan Kunci API

Ikuti 4 langkah mudah untuk mendapatkan ChatGPT (OpenAI) API

  • 1
    Kunjungi Platform OpenAI

    Buka platform resmi OpenAI (platform.openai.com) pada browser Anda.

  • 2
    Masuk ke Akun Anda

    Masuk atau daftar dengan akun OpenAI Anda yang telah terdaftar.

  • 3
    Buka Menu "API Keys"

    Masuk ke halaman API Keys lalu klik tombol Create new secret key.

  • 4
    Tempelkan & Simpan

    Tempelkan kunci berawalan sk-... ke form di sebelah kanan lalu klik Simpan Kunci API.
